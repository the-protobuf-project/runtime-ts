# @the-protobuf-project/network

Calls and serves protobuf services over HTTP. Generated clients take a
`Transport`; this package provides two, and a server handler:

|                    | What it speaks                                                     | Use it for                                              |
| ------------------ | ------------------------------------------------------------------ | ------------------------------------------------------- |
| `httpTransport`    | REST, through each RPC's `google.api.http` binding, with protojson | gRPC-gateway, ESPv2, Envoy transcoding, any AIP-127 API |
| `connectTransport` | The [Connect](https://connectrpc.com) protocol, JSON or binary, all four call shapes | connect-go, connect-es, Envoy, the Go and Rust HybridServers, `connectHandler` |
| `connectHandler`   | Serves implementations over Connect as a fetch handler             | `Bun.serve`, `Deno.serve`, Workers, Node, tests         |

```sh
bun add @the-protobuf-project/network
```

## Usage

### Call a service

```ts
import { connectTransport, httpTransport } from "@the-protobuf-project/network";
import { LibraryServiceClient } from "./gen/library/v1/services/library_service/client.ts";

// REST: POST /v1/{parent=shelves/*}/books with the book as the body
const rest = new LibraryServiceClient(
  httpTransport({
    baseUrl: "https://library.example.com",
    headers: async () => ({ authorization: `Bearer ${await token()}` }),
  }),
);

// Connect: POST /library.v1.LibraryService/CreateBook, binary bodies
const connect = new LibraryServiceClient(
  connectTransport({ baseUrl: "https://library.example.com", format: "binary" }),
);

const book = await rest.createBook(
  { parent: "shelves/poetry", book: { title: "Odes" } },
  { timeoutMs: 5_000, headers: { "x-request-id": crypto.randomUUID() } },
);
```

Every failure rejects with a `StatusError` from `@the-protobuf-project/errors`,
read from `google.rpc.Status`, Google's `{"error": ...}` envelope, a Connect
error body, or the HTTP status.

### Stream

`connectTransport` serves every call shape. What each needs from the platform:

| Call             | Over                                       | Bun, Node, Deno | Workers, browsers |
| ---------------- | ------------------------------------------ | --------------- | ----------------- |
| unary            | fetch                                      | yes             | yes               |
| server streaming | fetch                                      | yes             | yes               |
| client streaming | fetch, streamed request body (half duplex) | yes             | where fetch streams request bodies |
| bidi             | full-duplex HTTP/2, via `http2Duplex()`    | yes             | no                |

```ts
import { connectTransport } from "@the-protobuf-project/network";
import { http2Duplex } from "@the-protobuf-project/network/node"; // Bun, Node and Deno only

const duplex = http2Duplex();
const transport = connectTransport({ baseUrl: "http://localhost:8080", format: "binary", duplex });

for await (const shelf of transport.serverStream(watchShelf, { name: "shelves/poetry" })) show(shelf);
const { imported } = await transport.clientStream(importBooks, books());
for await (const reply of transport.bidiStream(chat, questions())) show(reply); // each as it arrives

duplex.close();
```

A stream that fails throws the call's `StatusError`, with its code, after the
replies that came before it. http:// URLs use cleartext HTTP/2 (h2c), which the
Go and Rust HybridServers serve on their HTTP port; https:// ones use TLS.

### Call through a Cloudflare service binding

```ts
const client = new LibraryServiceClient(
  connectTransport({ baseUrl: "https://library.internal", fetch: (url, init) => env.LIBRARY.fetch(url, init) }),
);
```

### Serve an implementation

```ts
import { connectHandler } from "@the-protobuf-project/network";
import { LibraryServiceDescriptor } from "./gen/library/v1/services/library_service/service.ts";

const handler = connectHandler([{ descriptor: LibraryServiceDescriptor, impl: new MyLibrary() }]);

Bun.serve({ port: 8080, fetch: handler }); // or Deno.serve(handler), or export default { fetch: handler }
```

Errors thrown by the implementation become Connect error bodies with the
matching HTTP status.

### Test without a network

```ts
const handler = connectHandler([{ descriptor: LibraryServiceDescriptor, impl: fake }]);
const client = new LibraryServiceClient(
  connectTransport({ baseUrl: "http://test", fetch: (url, init) => handler(new Request(url, init)) }),
);
```

### Write your own transport

```ts
import type { Transport } from "@the-protobuf-project/network";

const logging = (inner: Transport): Transport => ({
  async unary(method, request, options) {
    console.info(`${method.service}/${method.name}`);
    return inner.unary(method, request, options);
  },
});
```
