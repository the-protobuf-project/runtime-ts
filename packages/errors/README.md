# @the-protobuf-project/errors

Errors that carry a gRPC status code. Every client call, server handler and
Code Mode connector in runtime-ts rejects with a `StatusError`, so callers can
branch on `error.code` the same way whatever the transport was.

```sh
bun add @the-protobuf-project/errors
```

## Usage

### Throw a status

```ts
import { StatusError } from "@the-protobuf-project/errors";

throw new StatusError("NOT_FOUND", "shelves/poetry does not exist", {
  reason: "SHELF_MISSING", // google.rpc.ErrorInfo reason
  details: [{ "@type": "type.googleapis.com/google.rpc.ErrorInfo", reason: "SHELF_MISSING" }],
});
```

### Branch on the code

```ts
import { StatusError } from "@the-protobuf-project/errors";

try {
  await client.getShelf({ name: "shelves/poetry" });
} catch (e) {
  if (e instanceof StatusError && e.code === "NOT_FOUND") {
    // create it instead
  } else {
    throw e;
  }
}
```

### Map other error shapes

```ts
import { codeFromConnect, codeFromHttpStatus, codeFromNumber, toStatusError } from "@the-protobuf-project/errors";

codeFromHttpStatus(429); // "RESOURCE_EXHAUSTED", as google.api.http transcoding maps it
codeFromConnect("failed_precondition"); // "FAILED_PRECONDITION"
codeFromNumber(5); // "NOT_FOUND"
toStatusError(new TypeError("boom")); // StatusError with code "UNKNOWN", keeping the cause
```

`StatusError` serialises to `{ code, message, reason?, details? }` with
`JSON.stringify`, which is the shape Code Mode hands to sandboxed code.

### `@the-protobuf-project/errors`

| Export | Kind | Description |
| --- | --- | --- |
| `Code` | type | gRPC status codes, as names. |
| `StatusErrorOptions` | interface | Options for a StatusError beyond its code and message. |
| `StatusError` | class | An error carrying a gRPC status code; every client call and connector rejects with one. |
| `isCode` | function | Reports whether value names a gRPC status code. |
| `codeFromNumber` | function | Maps a numeric gRPC code (1-16) to its name. |
| `codeFromConnect` | function | Maps a Connect protocol code ("invalid_argument") to its name. |
| `codeFromHttpStatus` | function | Maps an HTTP status to the gRPC code google.api.http transcoding uses. |
| `toStatusError` | function | Wraps any thrown value as a StatusError, keeping one that already is. |
| `invalid` | function | Throws INVALID_ARGUMENT with a path-qualified message. |
